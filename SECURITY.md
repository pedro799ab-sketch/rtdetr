# Security Policy

## Supported versions

This is a research codebase; only the latest `main` branch receives updates.

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public Issue.
Instead, use GitHub's private [security advisory](https://github.com/pedro799ab-sketch/rtdetr/security/advisories/new) form to report it.

You can expect an initial response within 7 days.
